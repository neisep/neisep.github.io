**Just Another Git GUI** is a lightweight desktop Git client built in Rust with `egui`.

It focuses on the everyday local workflow first: review changes, stage files, commit, switch branches and inspect history. On top of that it adds a practical GitHub flow. You can publish an existing folder, sign in with GitHub device flow, push branches and jump straight to the relevant pull request page.

- Review diffs with line numbers and stage exactly what you want
- Built-in merge conflict editor with ours / theirs / live result
- Worktree support
- Native GitHub publishing and pull request flow
