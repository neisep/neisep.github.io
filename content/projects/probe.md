**Probe** is a native, fast REST client built with Rust and egui. It is a lightweight alternative to Postman and Insomnia, focused on speed, clarity and developer-first workflows.

- Requests live in plain `.http` files you can commit next to your code
- Paste a cURL command straight into the address field
- OAuth2: Authorization Code + PKCE, Client Credentials and Device Code, with automatic token refresh
- No cloud, no telemetry, no clutter
